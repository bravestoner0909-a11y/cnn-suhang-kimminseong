Supabase 기본 연결

Vercel에 올릴 때는 config.js에 값을 넣어두면 선생님은 링크만 누르면 된다. 값이 비어 있으면 여기서 한 번 입력해 저장하면 된다.

기본값은 이미 설정되어 있다. Storage bucket 안에 아래처럼 올리면 된다.

과적합 설명

과적합은 모델이 학습 이미지의 특징을 너무 외워서, 새 이미지에서는 정확도가 떨어지는 상태다. 예를 들어 학습 정확도는 계속 올라가는데 검증 정확도는 멈추거나 떨어지고 검증 손실이 커지면 과적합을 의심할 수 있다.

이 사이트는 데이터가 적으면 CNN 블록 수를 줄이고, 드롭아웃과 이미지 증강을 사용해서 과적합을 줄이도록 돕는다. 그래도 클래스당 이미지가 너무 적으면 모델이 그림의 본질보다 배경, 조명, 구도 같은 우연한 특징을 외울 수 있다.

전처리 설명

사진은 원래 크기와 비율이 다르다. CNN은 같은 크기의 숫자 배열을 입력받아야 하므로 모든 이미지를 같은 정사각형 크기, RGB 3채널, 0~1 범위의 숫자로 바꾼다. 이 과정을 거치면 apple, cherry, test.jpg가 같은 조건으로 모델에 들어간다.
